# Architecture — M1 development

Scoria retains iPlug2/IGraphics, C++17, the iPlug2OOS build conventions and the original identities: `TlDs` manufacturer, `Scor` product, AU type `aufx`, `com.TalosDSP.vst3.Scoria` and `com.TalosDSP.audiounit.Scoria`. Version 0.0.2 is a development increment, not a completed M1 release. Only native VST3 and macOS AUv2 are built. GUI remains 800×520 with PEDALS / AMP / CAB / FX.

## Audio path

`AudioEngine` applies input trim → envelope gate → frequency-shaped overdrive → NAM → direct FIR → output level. Global bypass crossfades to the original input and settles to an exact dry copy. Each implemented stage has an independent smoothed bypass. Controls use 10 ms ramps; gate attenuation uses its own 0.5 ms attack and user release, with 6 dB hysteresis. Gate threshold is dBFS; release is ms. The original overdrive uses bass attenuation before soft clipping, four interpolated substeps, post-clipping tone filtering and a 15 Hz DC blocker. It is inspired by a tight guitar boost, not an exact hardware emulation. Oversampling is limited to this stage; it reduces but does not eliminate aliasing. No synthetic waveshaper substitutes for NAM.

Input and output trims have independent ramps on opposite sides of the nonlinear chain. The engine uses fixed 256-frame scratch arrays and accepts arbitrary host block lengths by splitting internally. Stereo uses two independent NAM, gate, overdrive and FIR states; channels are never summed. Mono processing occurs once, then duplicates to stereo output. Both inputs are read before writes, including in-place buffers. Supported layouts remain 1→1, 1→2, 2→2. Invalid layouts silence outputs; missing stereo right input duplicates left. Nonfinite inputs/outputs and extremely small internal states are zeroed. Processing introduces no buffering delay; reported latency is zero. Filter phase and the response within the captured model/IR are not additional host buffering latency.

## NAM and assets

`NamAmplifier` wraps pinned NAM Core v0.5.4. A static object-library integration retains upstream architecture registration objects. The selected upstream compiles as C++17, so the project standard has not changed. Fast-math is not enabled. NAM is prepared with a 256-frame maximum, prewarmed off-thread, and run as two mono instances. The bundled RiffSmith Distorted capture requires **48 kHz**. There is no NAM sample-rate conversion: an enabled amp at another rate is explicitly unavailable/silent, with a visible status; global bypass still works. Gate, boost and IR support 44.1/48/88.2/96 kHz.

M1 accepts only the audited `riffsmith-distorted-v1` model, verified by SHA-256 before parsing. Missing, altered, malformed or other models are rejected without replacing a valid prepared instance. This deliberately limits the supported `.nam` configurations: upstream parsers assume valid dimensions/weight counts in places, and arbitrary user importing is deferred. Future approved models require provenance, a checksum, compatibility tests and an explicit stable ID. SHA validation operates on the exact bytes subsequently parsed, avoiding a second file read. Asset size is bounded. No user file dialog or absolute-path state is exposed.

The bundled model's metadata says `amp_cab`; therefore the development preset bypasses the separate IR. The independent Jester Cookie Monster IR is a genuine recorded 4×12 response. Enabling it with this model intentionally applies two cabinet colorations. This is **not** the requested amp-only Tight Rhythm factory preset.

`WavImpulse` decodes mono little-endian PCM16/24/32 or float32 RIFF WAV off-thread. It rejects invalid/truncated/nonfinite/unsupported inputs. IR preparation uses a 65-point windowed-sinc resampler when rates differ, with impulse-area scaling. It keeps the first 42.67 ms (maximum 4096 taps) and fades the last 128 taps to omit the long room tail. No peak normalization occurs. `Cabinet` uses a preallocated circular history and direct convolution. This is intentionally simple and zero-buffer-latency; benchmark costs before increasing IR length.

## Ownership and real-time contract

`AssetLoader` owns a preparation worker. Host reset changes atomic rate/generation requests; it does not construct or reset NAM. The worker loads and prewarms a complete candidate. An atomic pending pointer transfers exclusive ownership to the audio consumer at a block boundary. The previous active object moves into a single retirement slot; the worker deletes it. The audio consumer refuses another handoff while retirement is occupied. Stale generations never process. All pointer atomics and request types must be lock-free. In-progress preparation can finish after a new request but is discarded by generation checking. Asset arrival fades in over 10 ms. During preparation an enabled unavailable amp/cab is silent, not a fake pass-through effect.

No I/O, allocation, model construction, mutex wait, logging, UI call or heavy destruction occurs in Scoria's callback. NAM's fixed container selection only performs an atomic index read; no live slimming is exposed. Worker polling sleeps outside audio; no audio-thread wake-up primitive is needed. Stop audio before destroying the plugin: destruction joins the worker and reclaims the remaining objects. Host teardown can wait for preparation; it never happens in `ProcessBlock`. This design intentionally trades short silence after reset for a simple ownership proof. Gapless model switching is not implemented.

## Parameters and state

`Parameters.h` centralizes names, ranges, defaults and stable IDs. IDs 0/1/2 remain input/output/global bypass; IDs 3–15 append gate, overdrive, amp and cabinet controls. IR selector 0 is None (dry); value 1 maps to `jester-cookie-monster-v1`. A development preset enables gate, boost and the captured Distortion rig, with separate cab off. Disabled future effects have no fake automation controls.

Schema 2 stores int32 version, uint32 model/cab/preset IDs, then 16 doubles. `State.h` validates a candidate fully before committing values. Version 1 restores its original three values and bypasses all new effects, preserving M0 session sound. Unknown IDs/versions, nonfinite/out-of-range values and truncation are rejected. State remains little-endian like M0; supported native architectures are little-endian. GUI tab selection is transient. Framework parameter reads are lock-free, block-granular and individually atomic; simultaneous valid multi-parameter changes are not one atomic audio snapshot.

A build-local copy of the pinned iPlug2 AU wrapper fixes two state issues: preset mutation before validation, and testing a negative decode return as a boolean success. `cmake/AuStatePatch.cmake` requires the expected upstream code and fails configuration if it changes. Upstream source checkouts remain untouched. AU regression tests cover the actual adapter.

Complete assets and their licenses are copied into each bundle's `Contents/Resources/assets`. iPlug2 resolves that installed resource directory; no runtime source/build directory is compiled into the plugin. CMake verifies manifest hashes and fails when required assets are missing or altered.
