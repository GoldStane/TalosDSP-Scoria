# M0 architecture

The build follows iPlug2OOS's root include/find_package and `iplug_add_plugin` conventions, inspected at template commit `9b214c1121a0da1e8db14b86a565c942a3bfea7e`. Only VST3 and macOS AUv2 are requested. No standalone, web, CLAP, VST2, AAX, or proprietary resources are used. Dependency pins live in `cmake/Dependencies.cmake`; C++17 is supported by the selected upstream.

`src/audio/AudioEngine.h` is framework-independent, header-only DSP. M0 contains only two serial linear gain stages, algebraically combined into one gain. At reset the current settings apply immediately. During processing a changed target ramps linearly over 10 ms, including bypass to unity. Both trims are bypassed. This ramp changes amplitude, not latency. Once future nonlinear stages exist, input and output smoothing must surround those stages independently.

The engine reads both source channels before writing, supports in-place buffers, duplicates mono without summing, and preserves stereo. Only 1→1, 1→2 and 2→2 are negotiated. Unexpected layouts produce silence; missing input pointers produce silence (a missing stereo right channel duplicates left). Non-finite input/output and subnormals become zero. Finite signal levels are not clipped. No frame-sized scratch storage, allocations, locks, I/O, logging or UI calls occur in Scoria processing. Block size does not affect its memory use. Host adapter conversions use iPlug2's prepared buffers.

`src/plugin` owns host integration and IGraphics. Parameters use the framework's atomic values; compile-time checks require lock-free doubles and prohibit `PARAMS_MUTEX`. UI controls attach to host parameter IDs. Block processing reads a snapshot once per block: M0 automation is block-granular, with smoothing. Separate atomic reads may observe adjacent updates across two blocks; state is not a transactional audio snapshot. Heavy model/IR ownership is deliberately deferred to M1, which must prepare off-thread and document safe exchange/reclamation.

Automation IDs are input trim 0, output level 1, global bypass 2. IDs must remain stable. State schema 1 stores an int32 version followed by iPlug2's three parameter doubles; truncated, non-finite or unknown-version data is rejected before any parameter changes. The single default preset uses the same serialized state format. No model/IR/effect selection exists yet. GUI page selection is transient presentation state and intentionally not automated or serialized.

`Parameters.h` names the future fixed processing stages and amp choices without constructing fake DSP. GUI pages list unavailable controls rather than expose ineffective automation. Distortion is a high-gain amp voice. Octaver remains post-v1. System Arial is loaded through IGraphics; no font file, artwork, model, or IR is shipped.

Identity: manufacturer `TalosDSP` / fourcc `TlDs`, product display `TalosDSP Scoria` / fourcc `Scor`, version 0.0.1, AU type `aufx`. Bundle identifiers are `com.TalosDSP.vst3.Scoria` and `com.TalosDSP.audiounit.Scoria`. Keep these stable across updates. Zero reported latency matches the engine. This does not prove worst-case host callback timing; profiling and live host checks remain required.
